# Indoor Pool Surface Load Calculator

An ASHRAE-style natatorium estimate of the evaporation rate and surface load of an indoor pool, with an optional outdoor-air penalty.

## Live tool

[Open Indoor Pool Surface Load Calculator](https://nuhaaljuneidi.github.io/indoor-pool-load-calculator/)

## Features

- Inputs: pool surface area, water and air temperature, relative humidity, air velocity over the water, and pool cover.
- Optional outdoor-air load from outdoor temperature, humidity, and flow rate.
- SI and IP units, a load-status indicator, and a downloadable PDF report.

## Run locally

Open `index.html` in a modern browser. No build step is needed.
